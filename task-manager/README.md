# My Tasks — 2026

A simple personal task manager that runs locally and saves everything to `tasks.json`.

## Requirements

- [Node.js](https://nodejs.org) (any recent version, v14+)

## How to run

1. Navigate to this folder:
   ```
   cd task-manager
   ```
2. Start the server:
   ```
   node server.js
   ```
3. Open your browser:
   ```
   http://localhost:3000
   ```

## Features

- **V1** — Simple 3-column kanban: Working on / Do ASAP / Do Later
- **V2** — Timeline, Mon–Fri calendar swimlane, stats dashboard, drag-and-drop board
- Due date tracking with overdue / today / soon indicators
- Owner, tags, and notes per task
- Closed task audit trail
- All data saved automatically to `tasks.json`

## To stop

Press `Ctrl+C` in the terminal.
